# ClasseurRouges
Progamme qui store les notes des élèves sur ses 3 ans de cycle et genère des rapports par classe ou pas élève.

## Estructura

- `Lancer_Classeurs_Rouges.bat`: lanza la aplicacion (offline)
- `src/`: codigo (Server.ps1, Engine.ps1, ui.html, NativePdfExtractor.cs, XlsxWriter.cs)
- `data/`: base de datos JSON y copias de seguridad (ignorada por git)
- `Bulletins_Exemples/`, `Rapports_Excel/`: ejemplos y informes generados (ignorados por git)

## Uso

Ejecutar `Lancer_Classeurs_Rouges.bat` (Windows, requiere Edge).
